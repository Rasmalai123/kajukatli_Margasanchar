# **App Name**: MargaSanchār

## Core Features:

- Direction Selection: Allow users to select their destination from a list of predefined locations.
- Filtered Bus List: Display a list of buses filtered by the selected destination, showing bus number, ETA, and crowd level.
- Live Tracking: Show the real-time location of the bus on a static map, highlighting the user's location and the bus's current position.
- Offline SMS Simulation: Simulate querying bus arrival times via SMS in a chat-style interface with hardcoded responses.
- Trip Planner (Optional): Suggest the best bus and ETA based on the user's selected origin and destination. Use AI to rank the available buses based on past patterns.

## Style Guidelines:

- Primary color: Soft blue (#7BBEEA) to convey trustworthiness and calmness.
- Background color: Very light blue (#EAF3F8) to provide a clean and airy feel.
- Accent color: Teal green (#00A36C) for interactive elements and highlights, suggesting forward motion.
- Font: 'PT Sans', a humanist sans-serif that is suitable for headlines and body text. Note: currently only Google Fonts are supported.
- Use clean, minimalist icons to represent different destinations and crowd levels.
- Mobile-first, responsive layout with rounded buttons and a clean design to ensure a smooth user experience on small screens.
- Implement subtle animations for bus icon movement and page transitions to provide visual feedback and enhance user engagement.
