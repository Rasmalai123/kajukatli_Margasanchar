# **App Name**: MargaSanchār

## Core Features:

- Live Bus Tracking: Display real-time bus locations on an interactive map using data from Firestore.
- Route and Stop Search: Enable users to search for specific bus routes or stops.
- QR Code Scanner: Allow users to scan QR codes at bus stops to view incoming bus ETAs.
- Trip Planner: Suggest the best bus route and ETA based on the user's selected starting and ending stops.
- Real-time Alerts: Notify users of delays and overcrowding through real-time alerts via Firestore subscription.
- SMS/IVR Integration: Integrate SMS and IVR systems to provide ETAs via SMS and voice calls.
- Predicted Passenger Demand: Show the predicted passenger demand in chart, to give admin the estimate idea.

## Style Guidelines:

- Primary color: Desaturated cyan (#70BDB3) for a calm and reliable feel, nodding to classic Indian transport colors without being cliche.
- Background color: Very light cyan (#E0F4F1), same hue as primary color but heavily desaturated.
- Accent color: Saturated teal (#468F88), a color analogous to cyan but with a strong difference in saturation to give highlights where needed.
- Body and headline font: 'PT Sans', a humanist sans-serif for readability on small screens.
- Use clear, flat icons for routes, stops, and alerts.
- Minimal, responsive layout optimized for small screens with clear information hierarchy.
- Subtle animations for live bus tracking and updates.
